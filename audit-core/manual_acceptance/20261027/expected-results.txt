Audit Rust V2 样例预期与实跑结果（按输入和配置独立计算）

S2-F01（合成文件基础/外部数据路径）
- 本期与上期工作簿由同一合成报表复制，只有文件名报告期不同；11 个匹配指标的环比变动预期均为 0。
- 配置含启用的校验规则，所以基础输入仍会有校验命中；本场景不能当作“无异常”样例。Rust 实跑摘要：15 条结果、4 条硬性异常。
- 加入外部工作簿后，Rust 读入 4 项外部指标，并报告 3 条外部数据提示；实跑摘要为 18 条结果、7 条异常（4 硬性、3 软性）。外部比较规则命中为 0，因此此路径只检查外部文件读取和输出链，不代表外部不一致已验证。
- 结果位于 `s2_f01/outputs/normal/` 与 `s2_f01/outputs/external_exception/` 的《报表审核清单》。输出完成时经过 Calamine 读回；本轮未对这组 S2 合成文件重跑 Python 对拍。

S2-F01（独立外部核对命中样例，`s2_external_hit/`）
- 输入与规则：本期存款余额 `1,234,567.89` 元；规则 `MANUAL-EXT-001` 对指标 `20202001` 使用“等于”、容差 0、硬性级别。配置和外部工作簿由 Rust writer 生成，预期由该规则和输入数值独立推导。
- 正常案例：外部值 `1,234,567.89` 元，绝对差 0；预期外部异常 0 条。实跑报告共 17 条结果、6 条异常，异常均为其他校验规则。
- 异常案例：外部值 `1,234,500.00` 元，绝对差 `67.89` 元；预期触发 1 条硬性外部异常。实跑报告共 17 条结果、7 条异常，其中外部核对 1 条、硬性异常 5 条。
- 两份输出均由共享 Calamine reader 成功重开；“外部核对规则”页实际读回报表值、外部值、差异值分别为 `1234567.89 / 1234567.89 / 0` 和 `1234567.89 / 1234500 / 67.89`，异常级别为硬性。该项只验证合成 CLI 样例，本轮未重跑 Python 对拍或真实业务样本。

S1-F02（合成任意行汇总与历史富化）
- `甲机构.xlsx` 有 2 行、`乙机构.xlsx` 有 3 行；按输入计数独立预期共 5 行。两本的批次、表单和规则字段由生成器固定，不依赖 Rust 结果推导。
- 历史工作簿给“甲机构”规则 1 提供两条匹配记录：触发数 10、12，分类“类别甲”“类别乙”，审核结果“通过”“未通过”；预期汇总为 `10|12`、`类别甲|类别乙`、`通过|未通过`。另有两条不同规则历史记录，预期总历史匹配 3 行。
- 正常输入预期结构检查 2/2 通过、汇总 5 行；Rust 实跑 history_rows_matched=3、data_rows=5。
- 结构异常输入另加表头“规则类型”改为“错误规则类型”的第三本，预期该文件被跳过，其他两本仍汇总 5 行；Rust 实跑检查 3 本、通过 2 本、跳过 1 本，原因 5/6 表头匹配。
- 输出位于 `s1_f02/outputs/normal/s1_f02_summary.xlsx` 和 `s1_f02/outputs/structure_exception/s1_f02_summary.xlsx`；两份均由 Rust Calamine reader 重开，正常输出历史字段逐项读回符合上述预期。该样例为合成 CLI 测试，不代表真实 S1-F02 人工验收或 Python/Rust 文件级对拍。
