### 106 条 Rust-only 的原因分类

1. **95 条旧 Python 提取失败相关差异**：涉及 13 份 Python 审核副本。把对应旧 Python 提取函数重新应用于这些副本时可复现 IndexError，导致旧提取器漏掉相应公式异常。Rust 的这些异常都来自模板命名校验区域中的公式。

#### 独立业务语义复核

独立只读复核将 95 条异常位置逐项与 19 类模板的 `校验区域*` 定义范围核对：95/95 均在对应命名校验区域内，没有越界或无法映射的项；模板公式与 Rust 重算副本公式逐字一致。例：个人贷款 `个人贷款发生额信息!K134` 属于 `校验区域_002`（`$I$4:$L$135`）；单位贷款 `单位贷款极端数据核查信息!I12` 属于 `校验区域_004`（`$H$3:$K$16`）。因此这些是模板自定义检查，不是区域外普通公式被 Rust 误当成审核规则。
