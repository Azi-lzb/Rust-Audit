# S3-F4 本期数值核对性能与输出对拍（2026-10-30）

## 负载

Windows x64 使用原 S3-F4 性能基准生成器，单份 10,000 行 CSV（14 列，1,199,062 bytes）、3.0 配置（6,678 bytes，4 张表）和 3.2 数值核对配置（5,688 bytes，2 张表）。每行构造唯一机构和指标记录，配置两条本期核对规则；两端都关闭独立运行日志，只比较结果工作簿。复用 Release SHA-256 `9112415fb15454136905aefdd694236006178c177e6f542b0cb83e0215ac7ba4`。预热一轮后交错执行三轮。

## 耗时

| 计时 | Python | Rust | Python / Rust |
|---|---:|---:|---:|
| 三轮中位数 | 7,071.61 ms | CLI 墙钟 989.30 ms | 7.15× |
| Rust 进程内服务计时 | — | 945 ms | 7.48× |

Rust 阶段中位数：配置读取 1 ms、输入读取 84 ms、业务计算 157 ms、工作簿写出和验证 702 ms。该阶段占 Rust 总服务时间约 74%，处理 20,000 条结果。Rust 当前明显快于 Python，且没有发现需要降低输出验证强度的证据；本轮没有修改产品实现。

## 输出正确性

- 两端均生成 20,000 条结果；输出工作簿均为“对比结果”1 张表，20,001 行（含表头）、17 列。
- 每轮比较 340,017 个单元格、100,000 个数值格，公式/缓存与关键结构也参与检查；预热和三轮比较全部 0 差异。
- Python 输出约 1,391,479 bytes；Rust 输出约 1,009,094 bytes。
- CSV 和两份配置输入 SHA-256 前后不变；只读 Python S3 源文件哈希前后不变。
- 单独进程树峰值工作集采样：Python 181.42 MB，Rust CLI 94.49 MB，均为一个进程。进程启动包含在内，采样间隔 5 ms。
