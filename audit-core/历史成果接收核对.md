## 路径与验证范围

- 根 Cargo.toml、audit-core、四个 Excel crates 与 sidecar 的 Cargo 路径指向仓库内；Cargo.lock 保留第三方依赖版本，第三方源码仍依赖现有缓存或正常获取，不能把本地 Excel-Core 独立等同于第三方依赖已全部 vendored。
- 对生产源码、Cargo 清单和根 BAT 的静态路径搜索未发现旧 Main、audit-dev、RustHistory 或 Codex 工作树的运行/构建引用；历史文档保留来源路径供追溯，不是运行依赖。外部重算引擎是按能力选择的可选依赖，S1 的完整强制重算仍需具体可用引擎。
- 可选 Linux openpyxl 暂存脚本曾在目标尚未创建时检查目标目录，移动后又沿用旧临时解释器路径；本轮作最小路径修正。没有运行暂存、打包或 Linux 部署；实际 runtime 的可重定位性和目标兼容性仍需验证。
- 本轮只做静态对照、格式与 diff 检查，没有编译、执行 Rust、运行测试、打包或推送。历史报告中的通过结论只适用于当时所列版本、输入和环境。
