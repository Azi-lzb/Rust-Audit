## 定位结论（全部有阶段级实测证据）

1. S3-F1 差距主因 = 验证阶段的第二次整簿解析（936ms，占写入阶段 66%）。
2. S1-F1 差距主因 = 冗余 Calculation 设置（~150ms/册）+ Excel 引擎固有成本
   （实例创建 ~2.3s 两端相当；Workbooks.Open 首册过滤器冷加载；逐表 Calculate
   重算本身 ~150ms/册）。
3. S5/S2 差距 = 进程启动 + 附加留痕输出（几十毫秒级），不值得优化。
4. S1-F2 语义不等价，维持不比对的口径。
