## 第二阶段：S1-F1 严格 A/B 与定点优化

### 关键发现（阶段级实测）

1. 旧 Python `_configure_application` 设 ScreenUpdating=False、
   EnableEvents=False、AskToUpdateLinks=False、Calculation=MANUAL（失败降级）；
   Rust 原生通道缺这些配置——自动模式下 Workbooks.Open 对 6,000 个脏公式触发
   隐式自动重算，与随后的显式计算构成双重计算。
2. 逐接口 Release 使 worker 关闭阻塞 ~215ms/批（Python CoUninitialize 即返）。
3. GetIDsOfNames 每次调用跨通道解析；Worksheets.Item / Workbook.Calculate
   等成员需要 METHOD|PROPERTYGET 组合标志（单 METHOD 报 0x80020003/6）。
4. S3-F1 验证阶段的公式检查原为第二次整簿解析（936ms）——上轮已改轻量扫描，
   本轮补齐 save/validate 分段计时证据（save 218ms / validate 417ms）。
5. 集合级 Worksheets.Calculate 在原生 COM 按名解析下不可用（0x80020006，
   组合标志亦然），保留逐工作表循环（与旧 Python 语义一致）。

### 修改文件

- `audit-core/src/native_office_com.rs`：configure 对齐旧 Python（四项设置 +
  Calculation=manual 降级式）；recalculate 带 stages_ms 返回与 mode 参数；
  DISPID 缓存；组合 dispatch 标志；生产计算改为 Worksheets.Item(i).Calculate
  循环；SaveAs 后 Close(False)；shutdown 直接进程退出（消除 ~215ms 阻塞，
  实测无残留 EXCEL.EXE 孤儿）。
- `audit-core/src/native_recalculation.rs`：worker 透传 mode、响应携带
  stages_ms、session_ready 携带 session_create_ms、快速退出。
- `audit-core/src/s3_execution_compare.rs`：验证去二次解析 + save/validate 分段计时。
- `sidecar/lo-convert/src/main.rs`：session.recalculate 新返回类型适配。
- `audit-core/tests/compare/perf_compare_20261030.py`：Rust 批次采集 stages_ms。
- `audit-core/tests/compare/s1f1_locate_20261030.py`（新增）、

### 严格 A/B 结果（交错 5 轮，热会话，2 册 × 6,000 公式，中位数）

| 阶段 | Python (pywin32) | Rust (native COM) |
| --- | --- | --- |
| Excel 实例创建 | 2,336ms | 2,640ms |
| 册1 open / calculate / save / close | 465 / 14.5 / 87.7 / 17.8 ms | 484 / 13 / 81 / 15 ms |
| 册2 open / calculate / save / close | 243 / 10.1 / 77.7 / 15.7 ms | 228 / 7 / 75 / 14 ms |
| 会话关闭 | 215.7ms | 4.6ms |
| **整批合计** | **~3,477ms** | **~3,835ms**（含 worker 进程启动） |

公式缓存核验：每轮每册两通道完全一致（6,000 公式 / 7,200 缓存值，20/20 输出）；
输入 SHA-256 前后不变；无残留 EXCEL.EXE。

### 结论

对齐 Excel 端配置并消除双重计算后，S1-F1 重算子步骤达到**与旧 Python 生产
通道统计平价（倍率 1.0，交错中位数）**；逐阶段中位数已全面持平或略优
（册2 计算 7ms vs 10.1ms、save 75 vs 77.7、close 14 vs 15.7）。
Excel 实例创建（~2.3s）为两端共同的主导成本，属 Excel 引擎固有。
基线对比（Goal 表格 0.72-0.77x）中的顺序偏差与缺失配置已在本轮消除。
