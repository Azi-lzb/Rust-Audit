## 关键结论（对齐空间盘点结果）

1. openpyxl 修改引擎（高级兼容路径）：**当前不可用，GUI 置灰**。实测三批次全部
   失败关闭——S1-F01 批次在“openpyxl changed OOXML relationships outside explicitly
   allowed worksheet relationship changes”处被后端校验拒绝；列尺寸被 openpyxl
   归一化（与旧 Python openpyxl 基线一致，故不声明 RowAndColumnDimensions）；
   S3-F03/S3-F05 的计划契约超出其保留集/DeleteColumn 不支持。负面证据记录全部
   原因；未来 openpyxl 后端补齐契约后重跑证据即可解锁。
2. WPS COM：重算通道原本只有 Excel.Application；现已支持强制 WPS 与自动探测
   （转换通道本就支持）。本机未装 WPS，强制 WPS 的真实重算冒烟属环境阻碍，
   记为待验收。
3. S1-F01 重算引擎顺序：auto = COM（Excel→WPS）→ LibreOffice，保持失败关闭、
   不自动换引擎语义不变（引擎间顺序即 auto 的既有语义）。
4. “S1F3 跨进程恢复”核实：是 S1-F01 人工重算恢复 worker（s1_recovery.rs，
   GUI 按钮“从审核副本恢复审核”），**不是** Python 菜单中暂缓的 S1-F3
   （组合工作表/联合模板）——属内部编号与 Python 菜单编号撞名，功能本身服务
   S1-F1 业务链。命名澄清已写入决策清单 AL-05，是否重命名待用户确认。
5. S3-F1 数值口径评估（AL-04）：旧 Python 基准即 IEEE-754，Decimal 化反而偏离
   基准；显示层已 0 差异，建议保持现状，待用户确认。
6. S3-F02 Python/Rust 对拍：**通过**（合成样本，4/4 行一致，differences=[]，
   9 项检查含值/公式/样式/名称/合并/冻结/筛选/页边距/元数据全过）。
7. S1-F02 对拍器（compare_s1_region_summary.py）夹具落后于当前 CLI 的表结构
   预检（合成样本表头 0/3 被跳过）——对拍器维护项，非业务缺陷证据；已记录待更新。
8. S2 基线生成器（run_s2_analysis_baseline.py）为只读基线生成，非对拍；本轮未扩展。
